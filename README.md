# IAM Projects & Identity Lifecycle Lab

## Overview

This repository documents hands-on Identity and Access Management (IAM) labs
designed to simulate common enterprise identity lifecycle and access management
processes.

The lab environment uses a simulated directory environment to demonstrate IAM
concepts and workflows commonly found in enterprise environments.

## Objectives

This portfolio demonstrates:

- Joiner-Mover-Leaver (JML) lifecycle management
- User provisioning and deprovisioning
- Role-Based Access Control (RBAC)
- Least privilege
- Group-based access management
- Access reviews
- Identity lifecycle management
- Access revocation
- Audit logging
- IAM automation

## Labs

| Lab | Description | Status |
|---|---|---|
| JML Lifecycle | Employee onboarding, transfers, and offboarding | In Progress |
| Provisioning & Deprovisioning | Granting and revoking access | Planned |
| RBAC | Role-based access assignment | Planned |
| Access Reviews | Identifying excessive or outdated access | Planned |

## Environment

- Simulated enterprise identity directory
- Python
- CSV/JSON identity data
- GitHub
- Simulated users, groups, roles, and applications

## Disclaimer

This is an educational IAM lab environment. It does not represent a
production Active Directory or enterprise IAM deployment. The simulated
environment is designed to demonstrate identity lifecycle, provisioning,
deprovisioning, access control, and governance concepts.
